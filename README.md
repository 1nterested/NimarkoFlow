# NimarkoFlow

### Ваш роутер. Ваше подключение.

Подписки с HWID, маршрутизация и управление подключением прямо в OpenWrt.

**OpenWrt · LuCI · sing-box · GPL-2.0-or-later**

[Установка](#установка) · [Сборка](#сборка-пакетов) · [Доступ и защита](SECURITY.md)

NimarkoFlow — приложение для роутеров OpenWrt с собственным интерфейсом в главном меню LuCI. Добавьте подписку, выберите режим маршрутизации и управляйте подключением в привычной панели роутера.

### Возможности

- **Встроенный интерфейс.** Обзор, подписка и помощь внутри LuCI, без отдельного кабинета.
- **Подписки с HWID.** Роутер автоматически отправляет идентификатор устройства провайдеру.
- **Импорт подключений.** HTTPS-подписки и ссылки VLESS, VMess, Trojan, Shadowsocks, Hysteria2/HY2 и TUIC. Фактическая поддержка зависит от установленного sing-box.
- **Два режима маршрутизации.** Весь трафик клиентов либо сервисы из списка `russia_inside`.
- **Управление в одном месте.** Подключение, отключение, обновление подписки и удаление профиля.
- **Ограниченная пользовательская роль.** Сохранённые ссылки и ключи не возвращаются в пользовательскую панель; API не предоставляет чтение UCI, файлов и журналов.

User-Agent по умолчанию: `Happ/5.7.0/ios/2609021014549 NimarkoFlow/0.1.0`. Его можно изменить при импорте, если провайдер требует точную строку клиента. Совместимость и правила привязки HWID определяет провайдер.

### Статус проекта

**0.1.0 — версия для разработки и проверки.** В репозитории находятся исходники, установщик локальных пакетов и демонстрационный `preview.html`. Готовые IPK/APK и канал автоматических обновлений пока не опубликованы. Проверки модели API пройдены; сборка SDK, исполнение ucode и установка на реальном OpenWrt ещё требуют проверки. Демонстрация UI не подключается к роутеру.

## Установка

### Что понадобится

- Роутер с OpenWrt и доступ администратора для установки.
- sing-box с поддержкой протоколов вашей подписки. Для XHTTP может понадобиться совместимый extended-вариант.
- Два пакета, собранные для вашей версии OpenWrt: `nimarkoflow` и `luci-app-nimarkoflow`.

Пока готового релиза нет, сначала [соберите пакеты](#сборка-пакетов). Для первой проверки используйте тестовый роутер или VM. Если установлено другое приложение маршрутизации, сохраните его настройки и удалите его штатным способом: установщик не выполняет автоматическую миграцию.

### На роутере с opkg

Скопируйте оба IPK и `install.sh` в `/tmp` роутера, затем выполните через SSH:

```sh
cd /tmp
sh install.sh ./nimarkoflow_0.1.0-1_all.ipk ./luci-app-nimarkoflow_0.1.0-1_all.ipk
```

Имена файлов — пример для версии 0.1.0; используйте фактические имена собранных пакетов. Установщик проверит OpenWrt, сохранит существующую конфигурацию NimarkoFlow в закрытую резервную копию, установит пакеты и перезапустит rpcd. Если sing-box отсутствует, он установит его из репозитория OpenWrt.

### На роутере с apk

Передайте установщику два APK вместо IPK:

```sh
sh install.sh /tmp/nimarkoflow-*.apk /tmp/luci-app-nimarkoflow-*.apk
```

В /tmp должна находиться ровно одна версия каждого пакета. APK должны быть подписаны ключом, которому доверяет роутер. Установщик не отключает проверку подписи.

### Первое подключение

1. Откройте **NimarkoFlow** в главном меню OpenWrt. При необходимости обновите страницу LuCI.
2. Во вкладке **Подписка** вставьте HTTPS-ссылку провайдера или ссылки подключения.
3. Выберите маршрутизацию и при необходимости измените User-Agent.
4. Нажмите **Сохранить и подключить**, затем проверьте статус во вкладке **Обзор**.

Подписка обновляется по расписанию каждый час; обновление можно запустить вручную. Новая подписка заменяет текущий профиль. Если провайдер уже привязал подписку к другому устройству, запросите сброс привязки у него.

## Сборка пакетов

Нужны Linux и чистый OpenWrt SDK для целевого релиза. Скопируйте или клонируйте этот репозиторий и выполните из его каталога:

```sh
sh build-sdk.sh /absolute/path/to/openwrt-sdk
```

Скрипт добавит оба пакета в SDK и запустит сборку. Результат находится в `bin/packages` внутри SDK. Для APK потребуется подпись своим ключом. Используйте SDK, совместимый с прошивкой устройства.

## Доступ и защита

Для обычного пользователя предусмотрена роль **`nimarkoflow-user`**. Она разрешает только статус, импорт и управление соединением. Сохранённые конфигурации не выдаются через этот API, а прямой Clash API слушает только loopback.

**Это ограничение доступа для пользовательской роли, а не защита от владельца роутера с root.** HWID проверяется провайдером и не шифрует уже полученные ключи. Пользователь с административными правами может прочитать локальные параметры. Инструкции по настройке отдельной учётной записи и ограничения приведены в [SECURITY.md](SECURITY.md).

Статус «Активно» означает работу службы, а не проверку доступности каждого сервера. При остановке восстанавливается обычная маршрутизация; kill switch в этой версии не включён. Удаление профиля не гарантирует стирание старых кэшей и резервных копий.

## Разработка и проверка

```sh
node tests/security.cjs
```

Тест проверяет модель поведения ограниченного API: ответы без секретов, проверку ввода, фиксированные команды, ACL и User-Agent. Он не заменяет запуск ucode и проверку реальных сессий rpcd. Проверки на устройстве описаны в [tests/OPENWRT.md](tests/OPENWRT.md).
