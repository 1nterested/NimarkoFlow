# Доступ и конфиденциальность

Роль `nimarkoflow-user` имеет доступ только к API `nimarkoflow`: `status`, `import`, `connect`, `disconnect`, `refresh`, `remove`. Ей не предоставляются права UCI, file.read, file.exec, shell, чтение журналов, кэшей или сырого sing-box API. Ответы API содержат только разрешённые поля состояния и фиксированные ошибки. Введённые секреты очищаются из формы после успешного сохранения; браузерное хранилище не используется.

Служба и RPC запускаются с umask 077, конфигурация UCI сохраняется с правами 0600, Clash API принудительно слушает только 127.0.0.1:9090. Подписка использует HTTPS. HWID автоматически передаётся провайдеру в заголовке X-HWID вместе с существующим профилем устройства; По умолчанию User-Agent равен `Happ/5.7.0/ios/2609021014549 NimarkoFlow/0.1.0`; его можно изменить при импорте. Разрешения и привязку проверяет провайдер, а не интерфейс. Для подписки, уже привязанной к другому устройству, может потребоваться сброс привязки.

**Root или пользователь с другими административными ролями может извлечь параметры из памяти и файлов роутера. HWID не шифрует конфигурацию и не является защитой от владельца устройства.** Здесь нет гарантии неэкспортируемых ключей. Полученные vless/hy2-параметры могут работать вне клиента, если сам сервер не ограничивает их использование. Обфускация и шифрование с ключом на том же роутере не решают эту задачу.

Роли rpcd суммируются: нельзя выдавать ограниченному пользователю `*`, `superuser`, старую роль приложения или роли с доступом к файлам/командам. Роль задаётся администратором в `/etc/config/rpcd`; пароль — уникальный crypt-хэш, никаких предустановленных паролей. Пример:

```uci
config login
    option username 'flow-user'
    option password '<CRYPT_HASH>'
    list read 'nimarkoflow-user'
    list write 'nimarkoflow-user'
```

После настройки перезапустите rpcd и проверьте реальные права этой сессии. Остальные пакеты LuCI также должны быть проверены: утечка через другую роль не закрывается этим приложением. Доступ к LuCI предоставляйте через HTTPS, не открывайте панель в WAN.

Подробные проверки перед выпуском: [tests/OPENWRT.md](tests/OPENWRT.md).
